# CNP Fraud Detection Database

A database and analytics project designed to detect and analyze Card-Not-Present (CNP) fraud using SQL queries and Python scripts.

## 📁 Repository Structure

- **`data/`**: Raw and processed datasets used for analysis.
- **`sql/`**: SQL queries, procedures, and schema setup (including MQ3 queries).
- **`python/`**: Python scripts for data processing, analysis, and modeling.
- **`query_outputs/`**: Saved outputs and analytical results from executed SQL queries.
